#  Clubly

**Clubly** is a smart club management platform designed to organize and manage sports club operations through a centralized digital system. It enables members to explore club activities, renew memberships, book training sessions, and manage schedules, while giving administrators and trainers efficient tools to control and monitor club services.

---

##  Problem

- Many clubs still rely on manual or unorganized systems.
- Scheduling conflicts and data errors are common.
- Members struggle to choose the most suitable sport for them.
- Members find it hard to access services easily.
- Administrators face challenges managing data and daily operations.

##  Solution

- **Automated Booking System** — prevents scheduling conflicts without manual intervention.
- **Centralized Database** — reduces data errors and ensures accurate records.
- **AI-based Recommendation System** — suggests the most suitable sport for each member based on age, personality, height, and weight.
- **Member Portal** — easy access to services, bookings, and personal activity tracking.
- **Admin Dashboard** — simplifies management, reporting, and decision-making.

##  Features

- Centralized platform for memberships, activities, reservations, and payments.
- Smart management of activity groups and facility utilization.
- Reduces double bookings and scheduling conflicts.
- AI recommendation system based on member data (height, weight, interests).
- AI-powered chatbot to answer members' questions about club services.
- AI-powered medical assistant for guidance on medical cases.
- Analytics dashboard for data-driven decisions.
- Simple, user-friendly browsing and booking experience.
- Multi-role support: Admin, Trainer, Member, and Guest.

##  System Architecture

The system follows a layered architecture connecting the frontend, backend, database, and AI components. See the `docs/` folder for the full architecture, ERD, use case, sequence, and class diagrams.

##  Tech Stack

**Frontend:** HTML, CSS, JavaScript, Visual Studio

**Backend:** ASP.NET Core Web API, Entity Framework Core, RESTful APIs

**Database:** SQL Server Management Studio (SSMS)

**AI / Data Science:** Python, Anaconda, Jupyter Notebook, VS Code

**Design & Diagrams:** Figma (UI/UX), Draw.io (system & ERD diagrams)

**Data Analysis:** Power BI

##  Methodology

The development followed a structured software engineering approach:

1. **Requirements Analysis** — identifying needs of Admin, Trainer, Member, and Guest roles.
2. **System Design** — UI/UX design using Figma.
3. **Implementation** — frontend UI and backend RESTful APIs.
4. **Database Development** — centralized database for users, memberships, activities, and reservations.
5. **Testing** — unit, integration, and user acceptance testing.
6. **Deployment & Evaluation** — assessed based on performance, usability, and reliability.
